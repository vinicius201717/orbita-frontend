# Mapa de rotas

Paths REST desta tabela são relativos a `BACKEND_API_URL` (`/api/v1`). “Integrada” significa que a tela chama um contrato existente e trata a resposta real; homologação externa de provedores continua separada.

`EMPRESA` significa `BUSINESS_OWNER` ou `BUSINESS_STAFF`; `DRIVER` e `ADMIN` são perfis distintos. Usuários sem sessão são encaminhados a `/login`; usuários de outra área são encaminhados ao próprio painel. O backend revalida autorização.

## Rotas internas do BFF

Estas rotas pertencem ao frontend, não são endpoints novos do backend.

| URL                      | Método           | Finalidade                                                          |
| ------------------------ | ---------------- | ------------------------------------------------------------------- |
| `/api/session`           | GET              | Consulta/atualização da identidade da sessão.                       |
| `/api/session/login`     | POST             | Login e criação da sessão opaca.                                    |
| `/api/session/register`  | POST             | Cadastro público validado, limitado a proprietário/entregador.      |
| `/api/session/logout`    | POST             | Encerrar sessão local e solicitar revogação remota.                 |
| `/api/session/socket`    | GET              | Access token curto para Socket.IO; nunca refresh token.             |
| `/api/backend/[...path]` | GET, POST, PATCH | Proxy autenticado, limitado aos paths/métodos aprovados no OpenAPI. |

O cliente não usa o proxy para autenticação bruta, webhooks, health ou confirmação pública por token. Rotas sem suporte exibem indisponibilidade, em vez de navegar para páginas ou endpoints fictícios.
